# Agent Starter Kits

[English](./README.md)

`agent-starter-kits` 是一组给 AI coding agent 使用的项目启动模板。

它把项目结构、agent 规则、本地工具说明、初始化边界提前放好，让新项目不用每次从零整理协作规则和基础文档。

这些模板适合做可复制的项目起点，也适合教学模板。用户可以用“初始化”“部署”这类简单自然语言，让 AI 按模板内规则快速搭建或运行对应项目。

## 当前包含

- Website 模板：用于本地 Next.js、React、TypeScript、PixiJS 项目。
- Expo 模板：用于 Expo React Native 项目环境。
- WeChat Mini 模板：用于微信小程序和微信小游戏项目。
- 每类模板都有英文版和简体中文版。

## 解决的问题

AI 参与开发时，很多时间会浪费在重复搭建基础层：仓库规则、项目文档、工具索引、凭证边界、fail-fast 工作流。

这些 starter kits 把这部分变成可复用模板。

## 设计重点

- Agent 能稳定遵守。
- 本地开发、工具、凭证和项目边界写清楚。
- README 保持简洁，具体 quickstart 和维护规则放在各模板内部。

## 模板族

| 模板 | 用途 |
| --- | --- |
| Website | 本地 Web 项目，默认 Next.js + PixiJS。 |
| Expo | Expo React Native 项目环境。 |
| WeChat Mini | 微信小程序和微信小游戏 agent 工作流。 |

选择匹配的模板目录，然后阅读该目录内的文档继续。
